# CalcMaster

CalcMaster is an all-in-one calculator project
built with Python.

## Phase 1: Calculation Engine

The first phase implements four basic mathematical
operations.

### Features

- Addition
- Subtraction
- Multiplication
- Division
- Division-by-zero protection
- Invalid-operation handling
- Automated unit tests

## Requirements

- Python 3.8 or higher

No external libraries are required.

## How to Run

Clone the repository and enter the project folder.

Run:

python3 main.py

## How to Run Tests

Run:

python3 -m unittest discover -v
